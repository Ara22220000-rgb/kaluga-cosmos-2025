# Проект «Моя семья — мой космос» 🚀
### Региональный этап Чемпионата «Московские Мастера» 2025
**Компетенция:** Веб-технологии (Юниоры)  
**Модуль А:** Разработка интерфейса пользователя

## 📋 Описание проекта
Сайт посвящен городскому мероприятию в Калуге, приуроченному к Году семьи. Цель ресурса — привлечение жителей и интеграция космической тематики в семейный досуг.

## 🛠 Технологии
*   **HTML5 / CSS3** (Семантическая верстка)
*   **Native CSS** (Использование фреймворков запрещено по ТЗ)
*   **Responsive Design** (Адаптив под 1920px и 796px)
*   **GIT** (Система контроля версий)

## 📁 Структура проекта
*   `/index.html` — Главная страница (Темная тема)
*   `/index-light.html` — Главная страница (Светлая тема)
*   `/registration.html` — Регистрация с формой для членов семьи
*   `/schedule.html` — Расписание конкурсов (сетка занятости)
*   `/account.html` — Личный кабинет участника
*   `/competition.html` — Описание конкурса (с поддержкой Print CSS)
*   `/404.html` — Страница ошибки
*   `/creative/` — Дизайн-макеты страниц (.png)
*   `/css/` — Каскадные таблицы стилей
*   `/img/` — Графические ресурсы и логотип

## ⚙️ Инструкция по запуску
Для просмотра сайта откройте файл `index.html` в браузере Google Chrome или перейдите по ссылке на GitHub Pages.
